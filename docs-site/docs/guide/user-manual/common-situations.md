# Solutions for common situations



**IceTrackVault** was written not just to play music, but to provide robust support for problems that music coordinators routinely deal with. This page will walk through typical issues before and during an event: missing music, incorrect files, swapped short and long programs, moving skaters between events, and applying updated EMS downloads.

## Missing Music

Last-minute requests from competitors who missed upload deadlines sometimes happen, and **IceTrackVault** can help. These requests may arrive too late to be uploaded to EMS, properly tagged, and downloaded - they need to be added directly to the competition project and placed into an event.
