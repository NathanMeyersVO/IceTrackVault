# Contact us

We welcome feedback, bug reports, and feature ideas from competition music staff and volunteers.

**GitHub (preferred if you have an account)** — open an issue on the project:

[github.com/NathanMeyersVO/IceTrackVault/issues](https://github.com/NathanMeyersVO/IceTrackVault/issues)

Issues are public and help others see known problems and planned fixes. Include your IceTrackVault version ( **Help → About IceTrackVault…** ) and a short description of what you were doing when something went wrong.

**Contact form (no GitHub account needed)** — reach the team directly:

[Contact form](https://forms.gle/38pZySw5F1Q8KAez7)

Use whichever channel is easier for you. We read both.
