# Using the app

## Projects and library

1. Open **Project → Projects…** and create a project, or **Import EMS download…** from a folder of EMS downloads.
2. Open a project. IceTrackVault scans project audio for MP3, FLAC, WAV, OGG, and M4A files and reads tags. Playlists and taglists load from `library/trackvault.json` (kept up to date automatically).
3. Double-click a track (or select and press play) to start playback.

## EMS updates

Use **Project → Apply EMS Download…** to stage a folder of EMS downloads, preview changes, and apply updates to the open project.

## Export and import

- **Project → Export Project…** saves the open project to a `.tvproject.zip` archive.
- In the Projects hub, **Import from archive** (file picker or drop zone) restores a copy as a **new** project (new ID).

## Stored collections

Create stored collections from the sidebar. Import and export `.tvcollection.zip` stored collections separately from full projects.
